分区扫描

读取分区表；深度模式全盘签名搜索被删/丢失的分区。

>
虚拟磁盘 · VMDK/VHD/VHDX虚拟机盘 → raw → 全链路恢复

删除的虚拟机/快照盘里是完整的NTFS/ext4卷。fixed VHD 与 flat VMDK 本身就是raw可直接用；dynamic VHD / sparse VMDK 是稀疏存储，先展开成 raw（洞=零、稀疏写），再跑分区扫描。VHDX v1 仅识别。

RAID重组 · NAS/服务器阵列RAID0/1/5 · 自动检测参数 · 缺盘可降级重建

RAID卡坏/阵列被拆后，用各成员盘的镜像重组虚拟盘：自动检测级别(RAID0/1/5)×条带大小×盘序×布局(四种经典)，按MBR/GPT/分区魔数打分。RAID5 缺一块盘也能用其余盘 XOR 重建。重组出的 raw 自动设为当前镜像接全链路。

兜底 · 监控裸流雕刻海康/大华等 · H.264/H.265无容器流

监控录像损坏后常只剩裸流（无文件名无容器）。按参数集+关键帧序列扫描，输出可播放文件。裸流原件始终保留，重封装MP4为尽力而为（B帧顺序可能不完美）。

深度 · Mac盘 HFS+目录树+提取 · APFS仅识别

Mac老格式盘(H+/HX)：catalog B树遍历出原名+路径+大小并按 extent 提取。HFS+ 无显式已删标记——catalog 残留记录会一并列出。APFS(Mac 10.13+)体量大，v1 仅识别容器。

深度 · exFAT已删挖掘全簇扫描 · 已删条目+孤儿目录

比目录树遍历更深：整目录删除后的孤儿目录簇、被覆盖旁路下的已删条目集都能挖出（原名+大小+时间）。目录项按规范 NameHash/SetChecksum 双校验。

深度 · ext4日志挖掘Linux/NAS · JBD2事务+已删文件

ext4 的 JBD2 日志里存着旧版目录块与 inode 表块——已删文件的名字+大小+数据位置常完整躺在里面。同时报告崩溃尾巴（有描述符无 commit 的未提交事务=掉电现场）。

微信图片 dat 解密

微信PC端缓存的聊天图片是单字节异或加密的 .dat——按图片头特征自动还原为 jpg/png/gif 等，保持原目录结构。

从哪找dat：恢复结果里的 FileStorage\Image 或 MsgAttach 目录；深度雕刻出的dat也能解。
原理：dat头 XOR 已知图片magic（JPG/PNG/GIF/BMP/WebP）反推密钥，整文件异或还原；探测不中的会如实跳过。

📧 PST/OST 检查Outlook邮箱文件 · 结构体检 + 头损兜底

Outlook 的 PST/OST：结构体检（两棵B树走查 → 目录/邮件/孤儿/缺块统计）；头损时全盘扫描描述叶页找回邮件清单。v1 为结构级检查（不解析正文），全量导出建议 readpst。

🧩 CHK文件识别chkdsk的FOUND.00X产物 · 魔数拆分

chkdsk 把丢失簇存成 FILE0001.CHK——里面常是完整文件或多文件拼接。按魔数识别类型并拆分提取（JPG/ZIP/PNG/PDF/MP4等可精确定界）。

>
🔐 加密检测/解锁BitLocker/LUKS/高熵区 · BitLocker可解锁

检测"数据还在但被锁"：加密卷头识别 + 逐MB熵扫描。BitLocker 卷支持密码 / 48位恢复口令 / 清除密钥解锁并解密成 raw 镜像（接全链路恢复）。

MP4视频修复

相机/行车记录仪/手机断电导致MP4缺少moov索引——用同设备的完好视频作参考，重建索引使视频可播放。

修复模式
原理：untrunc引擎分析参考视频的编码参数(SPS/PPS/采样率)，然后遍历损坏视频的mdat数据流逐帧重建索引。
参考视频要求：同一台设备、相同分辨率/帧率/编码设置录制。行车记录仪用同型号另一段完好录像即可。
限制：严重碎片化的视频可能部分帧丢失；加密的DRM视频无法修复。
>
📹 海康 .dav 剥离PS包装→裸流 + MP4重封装

海康DVR/NVR导出的 .dav(部分型号是 .mpg)是 MPEG-PS 包装： 剥掉 pack头/PES壳后就是标准 H.264/H.265 裸流，顺便重封装成能直接播放的 MP4。
